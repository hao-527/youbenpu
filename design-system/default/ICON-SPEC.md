# 图标设计规范

## 基本原则

- **永远不使用 Emoji 作为结构图标或标签**。Emoji 跨平台渲染不一致、不受设计系统控制、无法统一描边和颜色。
- 所有功能入口和分类图标统一使用 **Lucide 矢量图标**（SVG → base64 data URI），通过 `AppIcon` 组件渲染。
- 图标颜色继承当前语义 Token，不硬编码 hex 值。
- 图标必须搭配文字标签，不能单独图标表达含义。

## icon-bubble 规格

- 尺寸：72rpx × 72rpx
- 圆角：完全圆形（`border-radius: 999rpx`）
- 底色：对应语义色的 50 色阶（green-50、amber-50、red-50、slate-100）
- 图标尺寸：20px
- 图标颜色：对应语义色的 600 色阶

## 禁止事项

| 禁止 | 原因 |
|------|------|
| 使用 Emoji（🥛🍞💊🧴等）作为分类标签或图标 | 不可控渲染、无法调色、不符合无障碍标准 |
| 使用 PNG/JPG 图标 | 不可缩放、暗色模式失效 |
| 图标无文字标签独立使用 | 可识别性差、不符合 WCAG |
| 在 icon-bubble 内放文字 | 只放矢量图标 |
